# OG_Wallpaper

OG_Wallpaper is a Flutter-based mobile application.

## Features

- Browse wallpapers by different categories.
- View wallpapers in full-screen mode.
- Save wallpapers to the favorites section.
- Smooth navigation between multiple screens.

## Technologies Used

- Flutter
- Dart
- VS Code
